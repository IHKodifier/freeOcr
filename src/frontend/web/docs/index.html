Developer REST API Documentation

Integrate freeOCR.me's high-throughput, ephemeral OCR engine directly into your automated pipelines. Standard REST endpoints, real-time Server-Sent Events (SSE), and zero disk retention.

POST /api/v1/ocr/upload

Initiates an asynchronous OCR conversion job. Uploads are processed strictly in volatile Linux RAM disk (tmpfs). Accepts PDF, PNG, JPG, or JPEG up to active session quota (100 MB free base limit, expandable to 1 GB).

curl -X POST "https://freeocr.me/api/v1/ocr/upload" \
  -H "Accept: application/json" \
  -F "file=@scanned_contract.pdf"
GET /api/v1/jobs/{job_id}/stream

Subscribes to live Server-Sent Events (SSE) emitting real-time conversion progress per page, current state (QUEUED, PROCESSING, COMPLETED), and page bounding count.

curl -N "https://freeocr.me/api/v1/jobs/job_98a76b54/stream" \
  -H "Accept: text/event-stream"
GET /api/v1/jobs/{job_id}/download?format=pdf

Downloads the generated output. Format parameter accepts pdf (dual-layer searchable PDF ISO 32000-1), txt (raw text string), or md (layout-aware Markdown).

curl -O "https://freeocr.me/api/v1/jobs/job_98a76b54/download?format=pdf"
GET /api/v1/jobs/batch-download/zip?job_ids=id1,id2

Streams an in-memory ZIP archive (freeOCR_searchable_batch.zip) bundling multiple converted documents in a single HTTP transfer.

curl -O "https://freeocr.me/api/v1/jobs/batch-download/zip?job_ids=job_1,job_2&format=pdf"
GET /api/v1/config

Queries platform-wide quotas and dynamic configuration parameters (base limits, boost step sizes, queue names).

curl -s "https://freeocr.me/api/v1/config" | jq .
